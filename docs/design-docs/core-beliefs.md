# Core Beliefs

1. Business behavior has one source in Domain and Application Services.
2. The CLI proves a use case before the GUI consumes it.
3. Authentication is a reusable prerequisite, not duplicated inside features.
4. AWS and Windows are replaceable boundaries behind small ports.
5. Failures must be typed, actionable, observable, and safe to retry when declared.
6. A session or tunnel has an explicit owner and deterministic cleanup.
7. Repository evidence is more trustworthy than conversational memory.
