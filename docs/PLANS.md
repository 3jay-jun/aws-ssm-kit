# Execution Plan Protocol

Create `docs/exec-plans/active/NNN-title.md` for non-trivial work.

Each plan records:

- user outcome and non-goals;
- affected authorities and modules;
- acceptance criteria and expected failure modes;
- implementation steps and exact verification commands;
- security, process, port, network, and file side effects;
- decisions, deviations, blockers, and next step;
- progress backed by pass/fail evidence.

Update it during work. Move it to `completed/` only after all required gates pass.
Put accepted unfinished work in `tech-debt-tracker.md`, not hidden comments.
